# Activity 1: Setting Up C/C++ Development Environment

- Installed Visual Studio Code on Windows.
- Installed the Microsoft C/C++ extension for IntelliSense and debugging support.
- Installed the MinGW-w64 GCC compiler toolchain using MSYS2.
- Configured the system PATH environment variable to point to the compiler binaries.
- Verified the installation via terminal using `gcc --version` and `g++ --version`.
- Created, compiled, and executed `hello.c` to display "Hello, World!".
